1 · Dataset selection

The dataset

The lab asked for a large, relevant dataset from a reliable source, suitable for classification or regression. This project uses the course dataset supplied for the lab — file Social_media_impact_on_life_0_5e7l.csv — a recent, student-focused dataset with a clear three-class target. No source link is invented: the file name above is the dataset as supplied.

👥
4,500

rows (students) — a large dataset for a lab project, big enough for a stable 80/20 split.

🧩
16 columns

15 inputs + target. Student_ID is an identifier and is dropped before modelling.

🎯
3 classes

Target: Overall_Impact — Beneficial, Neutral or Negative.

⚖️
Classification

The target is a category, not a number — so this is a classification problem.

Why this dataset? It is directly about student life, it mixes numerical and categorical features (so scaling + encoding really matter), it is large and recent, and the question it asks — is social media helping or hurting this student? — is one a model can actually answer from usage, sleep, stress and grades. That is exactly what the lab instructions ask the dataset choice to justify.

Target distribution — the classes are imbalanced

Beneficial 3,681 (81.8%) · Neutral 654 (14.5%) · Negative 165 (3.7%) of 4,500 students. In the 900-student test set the split is 736 / 131 / 33 — this matters when reading accuracy, see the Performance section.

2 · Preprocessing & exploratory analysis

Cleaning the data, then exploring it

🧹 Missing values

Perceived_Stress_Score: 46 missing · Academic_Performance_GPA: 85 missing. Both were filled with the median — a safe choice that does not pull the average toward outliers. After filling, 0 missing values remained.

🔁 Duplicates

0 duplicate rows found in 4,500 records, so no rows had to be removed. Every student in the file is a distinct record.

⚙️ Scaling & encoding

Numerical features were standardised (StandardScaler: mean 0, std 1) and categorical features one-hot encoded. 14 input features became 32 encoded features for the models.

Pipeline — from raw file to trained model

1 · Load

4,500 rows × 16 columns from the CSV.

2 · Clean

Median-fill 46 + 85 missing values; check duplicates (0).

3 · Encode

Label-encode the target (Beneficial=0, Negative=1, Neutral=2); scale + one-hot the inputs → 32 features.

4 · Split & train

80/20 stratified split (3,600 train / 900 test, random_state=42), then train 4 models.

Test accuracy

Random Forest and SVM tie on accuracy (0.9667) — so accuracy alone cannot pick the winner.

Macro F1-score — the deciding metric

Macro F1 averages the F1 of all three classes equally, so the tiny Negative class counts as much as the big Beneficial class. SVM wins: 0.9332.

Reading the table: KNN is clearly weakest, especially on the small Negative class (recall 0.667). Decision Tree and Random Forest reach 1.0000 training accuracy — a sign they memorised the training data (see Performance). SVM has the best balance: highest macro recall (0.9470) and highest macro F1 (0.9332), and it was saved as best_model.pkl.
Best model deep dive · SVM

Why the SVM won

The Support Vector Machine with an RBF kernel finds a curved boundary in the 32-dimensional encoded feature space. With class_weight="balanced" it pays extra attention to the rare Negative class, which is why its recall on that class (0.909) stays high despite only 33 Negative students in the test set.
